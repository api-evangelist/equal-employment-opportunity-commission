# U.S. Equal Employment Opportunity Commission (EEOC)

> The EEOC is the US federal agency that enforces the laws making it illegal to
> discriminate against a job applicant or employee because of race, color, religion,
> sex (including pregnancy, childbirth, gender identity and sexual orientation),
> national origin, age (40 or older), disability or genetic information. It collects
> the EEO-1, EEO-3, EEO-4 and EEO-5 workforce demographic reports and publishes
> aggregate statistics from them.

## What an agent can and cannot do here

**There is no EEOC API.** As of 2026-09-06, probing every EEOC-controlled host found no
OpenAPI or Swagger document, no GraphQL endpoint, no MCP server, no A2A agent card, no
SOAP/WSDL surface and no gRPC service. `api.eeoc.gov` and `publicdata.eeoc.gov` do not
resolve. The `github.com/EEOC` organization exists but has zero public repositories.

**The one machine-readable document EEOC serves** is its federally mandated public data
listing: `https://www.eeoc.gov/data.json` — a Project Open Data v1.1 / DCAT-US
`dcat:Catalog` of 140 dataset records. Every distribution in it is a file download
(XLSX, CSV, ZIP) or an HTML landing page; none is an API endpoint. Its newest dataset
`modified` date is 2019-08-19, roughly six years behind the human pages, so an agent
should treat it as a historical inventory, not a current index.

**The interactive data tool ("EEOC Explore")** is a set of Tableau Public workbooks
embedded in eeoc.gov pages (workbook `EEO1_17107864490220` on `public.tableau.com`).
Tableau Public is a third-party host; EEOC publishes no query contract for it, and its
data endpoints are protected by a bot challenge. Do not treat it as an EEOC API.

**Bulk data** is the supported programmatic path: the EEO-1 public-use files are XLSX
downloads linked from the statistics pages, currently running through the 2023 PUF.

## Licensing

Every dataset in the EEOC public data listing is `accessLevel: public` and dedicated to
the public domain under <http://www.usa.gov/publicdomain/label/1.0/>. There is no
pricing, no plan, no key and no quota.

## Notes for machine consumers

- `/.well-known/` is blanket-denied: every path under it returns HTTP 403 on both
  `www.eeoc.gov` and `eeoc.gov`, including paths that do not exist. No security.txt,
  no api-catalog, no agent card can currently be served from the primary domain.
- `eeocdata.org` and `data.eeoc.gov` both 301 to
  `https://www.eeoc.gov/data/eeo-data-collections`; they answer HTTP 200 with an HTML
  shell for arbitrary paths, so a 200 from either is not evidence of a document.
- No rate limits are published, and no `RateLimit-*` or `Retry-After` header was
  observed on any response. Be conservative when bulk-downloading.
- The EEOC Open Government Plan commits to describing how data assets are made
  "available for download and/or use through an application programming interface
  (API)". No such API has shipped.
